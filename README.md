# steady-app
Steady — a privacy-first habit tracker for Android. Local-only data, no accounts, no cloud.

About Steady
Steady is a calm, privacy-first routine planner. Track check-ins, numeric targets, and medication schedules with generous streak freezes, honest local insights, and full data ownership — no accounts, no cloud, no analytics trackers.
100% offline — all data lives in a local SQLite database on-device
Gentle streaks — freeze days and retroactive recovery so one bad week doesn't erase your history
All habit types — simple checks, numeric counts, and multi-slot medication reminders
Health Connect sync — steps, hydration, and sleep auto-fill relevant habits, on-device only
Deterministic note insights — a local tone engine, not a cloud AI, reads your journal
True data portability — CSV/JSON export and AES-256-GCM encrypted backups
About this repo
This repository contains the static landing page for Steady, published via GitHub Pages. It's a single self-contained index.html — no build step, no framework, no dependencies beyond a Google Fonts import.
